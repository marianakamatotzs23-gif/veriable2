Technical Specification & Protocol Whitepaper

        
        

            
1. Access Architecture: Web Showcase vs. Sovereign Desktop Node Option

            
    
                
  • Web Showcase and Quick Access: The web interface (veriable2.com) serves as an accessible entry point to the ecosystem, an informational showcase, and a distribution hub for downloading the desktop application. Users can explore network metrics and general protocol status directly through standard web browsers.
    • 
                
  • Local Installation Option (Desktop Sovereign Node - veriable2.exe): Alongside the web interface, users have the option to run the application directly on their local machines. The desktop client connects straight to the serverless peer-to-peer (P2P) Distributed Hash Table (DHT) mesh without relying on intermediary web servers or third-party web runtimes.
    • 
                
  • Independent Verification & State Enforcement: Operating a local desktop installation turns the client into an autonomous validation engine. Users independently verify block validity, engage directly in peer-to-peer block propagation, and enforce protocol invariant rules entirely on their own hardware.
    • 
            


            
2. Infinite Multi-Space Matrix & The 1 - 99 Depth Rule

            
    
                
  • Infinite Space Organization: Physical data blocks are never pooled into a monolithic file or folder. Ledger storage expands dynamically across infinite space partitions (space_1, space_2 ... space_N).
    • 
                
  • 1 to 99 Depth Scale: Each individual space directory preserves a minimum of 1 and a maximum of 99 block states. Upon sealing the 99th index, the protocol automatically spawns the subsequent space partition, precluding local filesystem congestion.
    • 
                
  • Asymmetric State Pruning & Base Anchors: During non-affinity epochs or storage pressure, historical transactions are physically purged from disk, anchoring the shard down to a lightweight 1.0 base state (BASE_LOCKED). Over 90% of physical storage overhead is decoupled while safeguarding block cryptographic integrity.
    • 
                
  • Cryptographic Snapshot Elevation: When a remote shard is synced, the payload is maintained under 1.0 quarantine until full SHA-256 snapshot confirmation elevates it back to the 99.0 active state.
    • 
            


            
3. Helper Token (Shield Coin): Tiered Power & Decimal Damping Economics

            
    
                
  • Dual Functional Division: Main Coin functions as a strictly capped store of value bounded by 21,000,000, while Shield Coin acts as an elastic, algorithmic shock absorber engineered to counteract market volatility.
    • 
                
  • Tiered Power Milestones: Shield Coin impact power and mining difficulty begin at 99.0 and scale down through definitive cumulative supply milestones:
                    
      
                        
    • 0 – 1,000 Coins: 99.0 → 70.0 (Tier 1 Legendary Tokens)
      • 
                        
    • 1,000 – 100,000 Coins: 70.0 → 50.0 (Tier 2 High Tokens)
      • 
                        
    • 100,000 – 4,000,000 Coins: 50.0 → 30.0 (Tier 3 Medium Tokens)
      • 
                        
    • 4,000,000 – 10,000,000 Coins: 30.0 → 10.0 (Tier 4 Low Tokens)
      • 
                        
    • 10,000,000 – 20,000,000 Coins: 10.0 → 1.0 (Tier 5 Weak Tokens)
      • 
                        
    • 20,000,000+ Coins (Infinite Space): Decimal damping scales down every 10,000,000 coins (0.1, 0.01, 0.001...), exponentially narrowing the PoW target space.
      • 
                    
    
                
    • 
                
  • Asset Value Pegging (Peg Price): During market downturns, participants burn Shield Coins to anchor their effective holding price against a predetermined baseline.
    • 
                
  • Asset Value Boosting (Boost Value): Users deploy Shield Coin impact power to scale effective asset value beyond prevailing spot prices.
    • 
                
  • Permanent Burn & Supply Contraction: Triggering stabilization mechanisms permanently routes consumed Shield Coins directly to the unrecoverable dead address (0x000000000000000000000000000000000000dEaD).
    • 
            


            
4. Dual Mining Mathematics & Asymptotic Emission Curves

            
    
                
  • Universal 99.0 Base Power: Every initialized node commences mining operations with an abstract base computational power of 99.0.
    • 
                
  • Main Coin Mining: Provides an unvarying 50 Main Coins per block. Difficulties scale smoothly across the 21,000,000 supply cap, permanently locking power at 0.0 once the ceiling is reached.
    • 
                
  • Shield Coin Mining (99 → 0.000000001 Perpetual Asymptotic Floor): Shield Coin issuance is never terminated. Emission decelerates toward an asymptotic lower bound of 0.000000001, never reaching absolute zero, guaranteeing perpetual network liquidity.
